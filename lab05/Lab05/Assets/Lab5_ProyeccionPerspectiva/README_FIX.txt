FIX V2 - Laboratorio 5

Correcciones:
- Se corrige el color rosado/magenta usando un shader compatible con URP o Built-in.
- Se reduce el tamaño de los textos de instrucciones.
- Se cambia el fondo de cámara para que no dependa de Skybox.
- Se ajusta la posición de los textos.

Cómo aplicar:
1. Cierra Unity o elimina la carpeta Assets/Lab5_ProyeccionPerspectiva anterior.
2. Copia esta nueva carpeta Assets dentro del proyecto.
3. Abre Unity y espera que compile.
4. Entra a Tools > Laboratorio 5 > Generar escenas.
5. Abre nuevamente las escenas generadas.

Si Unity mantiene materiales rosados por caché:
- Elimina la carpeta Assets/Lab5_ProyeccionPerspectiva/Materials.
- Ejecuta otra vez Tools > Laboratorio 5 > Generar escenas.
